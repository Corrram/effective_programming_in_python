# Effective Programming in Python

Course repository of the lecture **Effective Programming in Python**
(University of Freiburg, winter semester 2026/27).

## Getting started

1. Clone the repository: `git clone https://github.com/Corrram/effective_programming_in_python.git`
2. Open the folder in PyCharm or in VS Code.
3. Run `main.py`.

## Contents

- `main.py`: a first script to check that everything works
- `weather_data_analyzer.py`: a small example that we extend during the lecture
